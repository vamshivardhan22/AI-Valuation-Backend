# AI Valuation Backend

A FastAPI backend for an AI-assisted property valuation application. It provides API routes for house-price estimates, rent estimates, land valuation, detailed property analysis, Google sign-in, and image-based damage detection.

## Features

- House-price estimation using an ONNX LightGBM model, with a basic fallback calculation when prediction fails.
- Rent estimation using the predicted property value and city-based rent ratios, with adjustments for furnishing and parking inputs.
- Land valuation using city-rate data, zoning factors, road-width factors, and an inflation adjustment.
- Detailed property valuation and price insights through protected endpoints.
- Google OAuth sign-in and JWT-protected routes.
- Property damage classification from uploaded JPG or PNG images using an ONNX model.
- Interactive API documentation provided by FastAPI.

## Tech stack

- Python
- FastAPI and Uvicorn
- ONNX Runtime
- NumPy, pandas, scikit-learn, and joblib
- SQLAlchemy and PostgreSQL driver
- PyJWT and Google OAuth integration

## Run locally

Requirements: a supported Python version, pip, and the model files expected by the application.

```bash
git clone https://github.com/vamshivardhan22/AI-Valuation-Backend.git
cd AI-Valuation-Backend
python -m venv .venv
```

Activate the environment, then install dependencies:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

Set the required environment variables before starting the service. At minimum, configure `DATABASE_URL`, and configure the Google OAuth and JWT values for authentication flows. Keep secrets in a local environment file or deployment secret store; do not commit real credentials.

```bash
uvicorn app.main:app --reload
```

Open http://127.0.0.1:8000/docs for the Swagger API documentation. The repository's deployment configuration also defines a Uvicorn startup command.

## API areas

| Area | Purpose |
| --- | --- |
| `/predict/house-price` | Estimate a house purchase price and provide a range and summary. |
| `/predict/house-rent` | Estimate monthly rent. |
| `/predict/land-price` | Estimate land value. |
| `/predict/property-valuation` | Return detailed property insights; JWT required. |
| `/predict/valuation` | Return property valuation insights; JWT required. |
| `/predict/land-valuation` | Run the detailed land valuation service; JWT required. |
| `/damage/detect` | Classify a property-damage image; JWT required. |
| `/auth` | Authentication and Google OAuth routes. |

Request and response fields are validated by Pydantic models. Check the live Swagger schema for the full request formats.

## Model files and configuration

The prediction services expect model assets under the backend's model directory, including an ONNX price model, label encoders, and an ONNX damage model. These assets must be present at the paths referenced in the source code. Configure model paths and environment variables for your deployment environment.

## Important limitations

- Estimates are generated by models and heuristic fallback logic; they are not certified valuations or financial advice.
- Some endpoints use default values for inputs not collected by the request form. Results can therefore be approximate.
- Fallback calculations are intended to keep requests from failing, not to replace a validated model.
- Review authentication settings and CORS policy before production deployment. Do not use default or fallback JWT secrets in a public environment.
